The starting example · n = 3

Three stairs, three different routes.

Stand on the ground, labelled 0. You can move up one or two stairs. To reach stair 3, the complete possibilities are 1 + 1 + 1, 1 + 2, and 2 + 1. The order of moves changes the route: 1 + 2 visits stair 1, while 2 + 1 visits stair 2.

Choose a route and follow its actual landings

3 routes

Try 1 stair: only [1]. Try 2 stairs: [1, 1] or [2]. These give the initial answers dp[1] = 1 and dp[2] = 2. The route explorer lists every route for its selected n, including all 55 routes when n = 9.

Complete Python example · Backtracking

Try a move, explore it, then come back.

Backtracking begins at stair 0. At each position it tries +1, fully explores that choice, then tries +2. Reaching the top adds one to the counter. A choice beyond the top is skipped. The current stair is passed as an integer, so returning from the function automatically restores the caller’s stair.

For n = 3 the counter changes 0 → 1 for [1, 1, 1], 1 → 2 for [1, 2], and 2 → 3 for [2, 1]. The attempted move from stair 2 to stair 4 is pruned. For the source’s driver example n = 9, the printed answer is 55.

Derive the recurrence · n = 5

Five routes plus three routes makes eight.

Every route to stair 5 has exactly one last move. If that move is +1, the route must previously have reached stair 4. If it is +2, it must previously have reached stair 3. Remove the final move to see a one-to-one pairing with the smaller routes.

Complete Python example · Recursive search

Break nine stairs into smaller counting questions.

The first call asks for dp[9]. It asks dp[8] and dp[7]. Then dp[8] asks dp[7] and dp[6]. The second request for dp[7] repeats the same problem. That duplication continues all the way down to the known answers 1 and 2.

climb(3) = 2 + 1 = 3
climb(4) = 3 + 2 = 5
climb(5) = 5 + 3 = 8
…
climb(9) = 34 + 21 = 55

Complete, runnable Python

{{PYTHON_BRUTE}}

For n = 9, this version makes 67 function calls and 33 additions to get 55 routes. A call counts one invocation, not one route. The earlier n = 5 tree has nine calls and eight routes.

Complete Python example · Memoization

Store the first answer. Reuse the next request.

The first descent is 9, 8, 7, 6, 5, 4, 3. State 3 reads base answers 2 and 1 and stores 3. State 4 then stores 5. When state 5 requests state 3 again, the cached 3 is returned without exploring its children.

With these base-case checks, n = 9 takes 15 calls, 7 additions, and 5 cache hits. Cache hits occur at states 3, 4, 5, 6, and 7. The source uses an array mem initialized with −1; this Python adaptation uses a dictionary, where an absent key means “not computed.” Both store the same answers.

Complete Python example · Bottom-up DP

Fill every table entry up to the ninth stair.

We already know dp[1] = 1 and dp[2] = 2. Fill from left to right. Before calculating dp[i], both dp[i − 1] and dp[i − 2] are available. There is no recursive descent or return sequence.

The list has n + 1 slots so the stair numbers can be used directly as indices. Slot 0 is unused in this implementation. Only stairs 3–9 require additions: seven transitions produce the final 55.

Complete Python example · Space optimization

Keep two answers and roll them forward.

After computing a state, the next calculation no longer needs the oldest answer. Before stair i, a means dp[i − 2] and b means dp[i − 1]. Evaluate the old sum first, then let a take the old b and b take the sum.

Every rolling-variable update for n = 9
Stair iBefore (a, b)Old a + old bAfter (a, b)
3(1, 2)1 + 2 = 3(2, 3)
4(2, 3)2 + 3 = 5(3, 5)
5(3, 5)3 + 5 = 8(5, 8)
6(5, 8)5 + 8 = 13(8, 13)
7(8, 13)8 + 13 = 21(13, 21)
8(13, 21)13 + 21 = 34(21, 34)
9(21, 34)21 + 34 = 55(34, 55)

Complete, runnable Python

{{PYTHON_ROLLING}}

Python evaluates the right-hand side of a, b = b, a + b using both old values. Writing a = b followed by b = a + b would overwrite the old a: (1, 2) would incorrectly become (2, 4). When the loop finishes, b is 55. The source also shows this as a, b = b, a + b; no full table is needed.

Challenge: allow moves of 1 or 3 stairs
Define ways[0] = 1 for the empty route and ways[k] = 0 for k < 0. Then ways[i] = ways[i − 1] + ways[i − 3] for i ≥ 1. The counts for stairs 0–6 are 1, 1, 1, 2, 3, 4, 6. This is an added exercise, beyond the source chapter.


A small vocabulary
Connect the terms.
Dynamic programming · 动态规划Build answers using stored subproblem results.
State · 状态A precise description of one subproblem.
Overlapping subproblems · 重叠子问题Different branches ask for the same smaller answer.
Memoization · 记忆化搜索Cache answers as recursive calls solve them.
State transition · 状态转移方程The rule connecting a state to its dependencies.
Rolling variables · 滚动变量Retain just the values needed for the next state.
