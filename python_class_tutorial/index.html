KEEP THIS HANDY

A small class checklist.

When something breaks

  • AttributeError: did you assign self.name, or only a local name?
  • Argument-count TypeError: is self the first parameter?
  • Unexpected None: did the method return a result or only print it?
  • Another object changed: is a list shared, or do two names refer to one object?

Before calling it finished

  • Can you create two independent instances?
  • Does each method have a clear return contract?
  • Do rejected operations leave state unchanged?
  • Does the relationship mean “has a” or “is a”?
